# Historical WinForms-to-Avalonia Migration Assessment

## Scope

This document records a historical comparison between the retired WinForms application and the current Avalonia application.

It should be treated as a dated migration reference, not as an active roadmap or verification checklist.

## Historical Purpose

The original comparison was used to:

- identify legacy features that needed Avalonia equivalents
- track migration gaps during the transition period
- compare older WinForms UI behavior with the newer MVVM-based desktop app

## Current Use

Keep this file only for historical context when reviewing migration-era decisions.

Do not use it as:

- a current architecture map
- a current implementation checklist
- a source of active file paths, view names, or model names
- a list of work that still needs verification
