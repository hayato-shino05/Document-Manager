# Legacy WinForms Feature Reference

## Scope

This document describes the retired WinForms implementation that preceded the current Avalonia and .NET 9 application.

Use it only as historical reference when comparing older behavior, migration decisions, or legacy UI workflows.

It is not a current feature contract.

## Historical Context

- Version line: `3.1.2`
- UI stack: Windows Forms
- Runtime: .NET Framework 4.8
- Pattern: MVP with repository-style data access
