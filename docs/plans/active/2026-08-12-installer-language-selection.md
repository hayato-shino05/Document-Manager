# インストーラー言語選択と OS ロケール連携

## 目的

Inno Setup の言語選択を日本語、英語、ベトナム語、中国語に対応させ、初回起動時のアプリ言語を OS ロケールから決定します。既存の `app_settings.language` は優先し、対応外ロケールでは日本語を使用します。

## 実装単位

1. OS ロケールから `SupportedLanguage` を決定する共通マッピングを追加する。
2. 初回起動時だけ OS ロケールを設定へ反映し、既存設定を保持する。
3. Inno Setup の言語選択肢と既定値を追加する。
4. 言語マッピング、初回起動、既存設定保持、installer 構文を検証する。

## 制約

- データベーススキーマと既存の翻訳キーは変更しない。
- Windows 配布物のファイル配置、ショートカット、自己完結 publish を維持する。
- 未翻訳または対応外のロケールは日本語へフォールバックする。
